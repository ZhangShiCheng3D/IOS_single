## 项目：PixelStudio（像素画工具）

## 审查范围
逐个读取项目目录下所有 .swift 文件，以及 CLAUDE.md、README.md、Info.plist、Assets.xcassets 下的 Contents.json、Localizable.strings、*.storekit 文件。

## 审查清单（逐项检查并修复）

### 1. 编译正确性（最重要）
- 检查所有类型引用是否存在、是否拼写正确
- 检查方法签名是否匹配调用方
- 检查泛型约束是否正确
- 检查 @Model / @Observable / @MainActor 等标注是否正确使用
- 检查 Swift 6 严格并发：Sendable、actor 隔离、@MainActor 标注
- 检查可选值处理（解包、可选链）
- 检查 SwiftUI ViewBuilder 语法
- 修复所有会导致编译错误的代码

### 2. 架构一致性
- MVVM 分层是否清晰：Model 不应依赖 ViewModel/View
- ViewModel 应标注 @Observable 或 ObservableObject + @MainActor
- View 不应直接操作 SwiftData（应通过 ViewModel）
- 检查依赖注入是否正确（@Environment / 构造器注入）

### 3. SwiftData
- @Model 类的属性类型是否兼容（不能用集合里的可选等不支持的类型）
- @Relationship 是否正确标注（inverse）
- ModelContainer 配置是否正确
- 查询 @Query 使用是否正确

### 4. StoreKit 2
- Product ID 与 .storekit 文件中的一致
- Transaction 监听是否正确启动
- 购买状态缓存逻辑
- PaywallView 的购买按钮交互
- 恢复购买功能

### 5. 功能完整性
- 检查 CLAUDE.md 中列出的功能是否都有对应实现
- 检查是否有 TODO/FIXME/占位符代码
- 检查关键业务逻辑是否真正实现（不是空壳）

### 6. SwiftUI 最佳实践
- 检查 @State / @Binding / @Environment 使用
- 检查 NavigationStack / NavigationLink 使用
- 检查 List / ForEach 的 id 参数
- 检查 #Preview 宏是否有效
- 检查 .task / .onAppear 中的异步调用

### 7. 本地化
- 检查 Localizable.strings 中的 key 是否与代码中 String(localized:) / LocalizedStringKey 对应
- 中文和英文文件 key 是否齐全一致

### 8. 资源文件
- Assets.xcassets 的 Contents.json 格式正确
- Info.plist 配置完整（权限描述、ITSAppUsesNonExemptEncryption 等）

## 修复要求
- 发现问题后直接用 Edit/Write 工具修复
- 每次修复要确保不引入新的编译错误
- 如果发现缺失的文件（如某个 View 被 import 但不存在），直接创建
- 如果发现冗余文件，保留不删除
- 修复完成后，列出所有修改过的文件和修改摘要
