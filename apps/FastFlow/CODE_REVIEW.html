一、问题列表（按严重程度排序）

编译阻断 #1 · Utils/Extensions.swift 缺少 import UIKit

Haptics 枚举使用了 UINotificationFeedbackGenerator 与 UIImpactFeedbackGenerator，但文件仅 import Foundation / SwiftUI。 SwiftUI 不会自动导出 UIKit 的触感反馈类型，因此这两个符号在编译期无法解析， 会导致整个模块编译失败。Haptics 被 ViewModel、PurchaseManager、PlanPickerView 广泛调用， 属于阻断级问题。

修复：在文件顶部新增 import UIKit。

功能缺陷 #2 · Views/TrendsView.swift 体重趋势不随时间范围刷新

体重曲线（高级功能）通过 HealthKitManager.fetchWeightSamples(days: range.rawValue) 按所选范围取数，但加载只挂在 .task { … } 上、仅在视图首次出现时执行一次。 付费用户从「近 7 天」切到「近 30 天」时，weightSamples 不会按 30 天重新拉取， 导致体重图与所选范围不一致。

修复：.task { await loadWeight() } → .task(id: range) { await loadWeight() }， 范围变化即重新取数（TrendRange 为 Int 原值枚举，天然满足 Equatable）。

合规/上架 #3 · Info.plist 缺少 ITSAppUsesNonExemptEncryption

审查清单第 8 项与 README 上架检查均要求声明出口加密合规键。缺失时每次构建上传都会被反复询问。 App 仅使用系统标准加密（HTTPS 等），属豁免范畴。

修复：新增 <key>ITSAppUsesNonExemptEncryption</key><false/>。
