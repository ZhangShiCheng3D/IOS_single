全组合统一商业模式

整个组合有一条高度一致的产品哲学：一次性买断 + 纯本地运行 + 无广告无订阅无后端。这恰好是当前各赛道头部竞品的结构性软肋——绝大多数头部（CamScanner、Adobe Scan、Zero、Strong、Daylio、Calm、Dazz Cam、美图、Canva…）都已订阅化或重度内购。因此本组合的核心机会，统一来自「反订阅疲劳 + 隐私本地 + 垂直专注」这一被头部主动放弃的细分缝隙。

但同样地，这条哲学也带来一组共同短板：① 几乎全部仅 iOS、缺云同步与跨端；② 买断模式 LTV 低、难支撑规模化买量；③ 零品牌、冷启动获客难；④ 内容/素材/题库量难敌靠订阅持续供给的头部。13/15 的赛道竞争激烈度为「高」，意味着没有一款能靠正面拼量取胜，全部需要靠"利基定位 + 本地化 + 口碑种草"突围。

横向洞察（跨组合）

共同优势（可复用的护城河叙事）

  • 买断 vs 订阅：13/15 的赛道头部为订阅制，"一次付费永久用"是全组合统一卖点。
  • 纯本地 / 零上传：对隐私敏感品类（文档、相册、日记、用药）是无法被云端头部正面对标的硬差异。
  • 原生技术栈：Vision / HealthKit / Core Haptics / Live Activity / SwiftData / Metal，系统集成度与性能优于跨平台栈。
  • 无广告、轻量：相对靠广告变现且广告轰炸的免费竞品，体验干净。

共同短板（需系统性补齐）

  • 仅 iOS、无云同步：换机/多设备/平板场景体验落后，TAM 受限。建议全组合补可选 iCloud 私有同步。
  • 买断 LTV 低：单次收入无复购，难支撑规模化投放，获客高度依赖自然流量与口碑。
  • 零品牌冷启动：搜索词被头部占据，ASO 困难（PixelStudio 甚至撞名 500 万下载的同名 App）。
  • 内容/素材量难敌头部：相机、拼图、像素画、白噪音、解谜等"内容型"品类尤甚。

三条全组合级建议

  • 把"买断 + 纯本地隐私"做成统一品牌叙事。这是整个组合相对竞品订阅化的最大共性优势，可形成系列识别度（如统一的"无订阅·不上传"标识），降低单款冷启动成本。
  • 系统性补齐可选 iCloud 私有同步。"仅 iOS + 无云同步"是几乎每款的共同失分项，而 CloudKit 既保持"纯本地隐私"叙事、又解决换机/多设备痛点，是性价比最高的统一升级。
  • 资源向第一档倾斜、第三档谨慎止损。买断 LTV 低决定了无法对 15 款平均投放；优先把缝隙最真实的几款打成口碑标杆，再以系列品牌带动其余。
