⚠️ 剩余风险（需真机 / Xcode 验证）

1. 工程装配：仓库无 .xcodeproj，须在 Xcode 手动建工程并将全部源码、Assets.xcassets、 Resources/*.lproj、Info.plist、PrivacyInfo.xcprivacy 加入 Target（Build Phases 确认）。
2. 关卡可解性：10 关几何为静态设计，逻辑上可解；建议真机逐关跑通，尤其 Lv.5「夹缝」、Lv.10「环光」的解空间较窄。
3. 内购全链路：需用沙盒账号实测购买 / 恢复 / 家庭共享 / 断网降级，并在 App Store Connect 建 com.lumenpuzzle.unlock。
4. App 图标变体（可选）：当前为单一 universal 1024 图标，已可上架；如需 iOS 18 深色 / 单色（tinted）变体可后续补充。
5. 无障碍 / 动态字体：建议开 VoiceOver 与最大 Dynamic Type 抽查 HUD 与结算面板的截断情况。
