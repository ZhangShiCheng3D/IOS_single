二、逐项修复说明

编译错误 #1ScanWorkflowViewModel.swift

在 saveScannedImages 中，局部参数 runOCR: Bool 遮蔽了同名实例方法。 await runOCR(on:context:) 会解析到 Bool 局部变量并尝试“调用”它 → cannot call value of non-function type 'Bool'。

- await runOCR(on: document, context: context)
+ await self.runOCR(on: document, context: context)   // 显式 self. 指向方法
编译错误 #2EmptyStateView.swift

Swift 合成的逐成员初始化器不会为可选属性自动补 nil 默认值。 DocumentListView“无结果”态、FolderListView 子文件夹空态都只传 3 个参数，缺 actionTitle/action。

- var actionTitle: LocalizedStringKey?
- var action: (() -> Void)?
+ var actionTitle: LocalizedStringKey? = nil
+ var action: (() -> Void)? = nil
编译错误 #3PaywallView.swift

同上：ContentView 以 PaywallView() 无参调起付费墙，但 triggeringFeature 无默认值。

- var triggeringFeature: PremiumFeature?
+ var triggeringFeature: PremiumFeature? = nil
本地化 #4–6PaywallView / DocumentDetailView / PageTextEditor

Text(cond ? "key.a" : "key.b") 与 Label(cond ? "key.a" : "key.b", …) 中， 三元表达式的字面量会被推断为 String，命中 StringProtocol 重载而跳过本地化， 界面会直接显示原始 key。修复为 if/else 分支或显式声明 LocalizedStringKey 局部量：

// PaywallView：改 if/else
if purchaseManager.isPro { Text("paywall.restore.success") }
else { Text("paywall.restore.none") }

// Detail / PageTextEditor：显式类型
let favoriteKey: LocalizedStringKey = document.isFavorite ? "documents.unfavorite" : "documents.favorite"
Label(favoriteKey, systemImage: …)
配置 #7Info.plist
  • ITSAppUsesNonExemptEncryption = false：本应用零网络、无加密，显式豁免出口合规，避免每次上传 TestFlight 被询问。
  • UILaunchScreen = {}：SwiftUI 应用缺此键会以兼容模式（黑边）运行，无法占满现代设备全屏。
缺失文件 #8Configuration.storekit

新建本地内购测试配置：非消耗型产品 com.docscanpro.pro.lifetime，含中英文本地化与价格， 与 ProductID.pro 一致，可在模拟器测试购买 / 恢复 / 验证流程。

五、剩余风险与建议（未改动，留作权衡）

  • View 直接操作 SwiftData： DocumentListView/FolderListView/OrganizeDocumentView 直接调用 modelContext 做简单 CRUD，未经 ViewModel。这是 SwiftUI+SwiftData 的惯用简化写法，功能正确；若严格遵循 MVVM 可下沉到 VM，但属大范围重构，本次按“不破坏即不改”原则保留。
  • @AppStorage 置于 AppSettings: ObservableObject： 严格说 @AppStorage 设计用于 View，置于 ObservableObject 不会自动触发 objectWillChange。但本项目中这些值（OCR/质量/文本层）仅在扫描/导出时即时读取，且 Toggle/Slider 经 Binding 直写直读，实际无可见缺陷；外观偏好已手动 objectWillChange.send() 兼容。建议后续统一为 UserDefaults 计算属性。
  • 免费/专业门控粒度： 文件夹创建（FolderListView）当前无数量门控，标签上限仅在“单文档分配 > 3”时触发。若定价要求“无限文件夹/标签”为 Pro 专属，建议在创建入口也接入 isUnlocked(.unlimitedOrganization)。属产品策略取舍，未擅自改动。
  • AppIcon： AppIcon.appiconset 仅声明 1024×1024 槽位，缺实际 PNG（无法由代码生成），上架前需补图。
